# GitHub Clone 🚀

A full-stack GitHub-inspired web application that allows users to create accounts, manage repositories, explore projects, and interact with other developers.

## ✨ Features

- User Signup and Login Authentication
- JWT-based Authentication
- Create and Manage Repositories
- Public and Private Repository Visibility
- View Repository Details
- Search Repositories
- User Profiles
- Follow and Unfollow Developers
- Star Repositories
- User Profile Management
- Responsive GitHub-inspired UI

## 🛠️ Tech Stack

**Frontend:** React.js, JavaScript, CSS, Primer React

**Backend:** Node.js, Express.js

**Database:** MongoDB

**Authentication:** JWT, bcrypt.js

**Tools:** Git, GitHub, Axios, VS Code

## 🎯 Project Goal

The goal of this project is to understand full-stack web development by building a GitHub-inspired platform with authentication, repository management, database integration, and interactive user features.
